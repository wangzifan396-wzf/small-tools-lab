# BMI 计算

纯前端、零依赖的身体质量指数（BMI）计算工具。

## 功能
- 输入身高 (cm) 与体重 (kg)，实时计算 BMI。
- 健康分级：偏瘦 / 正常 / 超重 / 肥胖，并给出说明。
- 同时提供 **中国标准**（24 / 28）与 **WHO 标准**（25 / 30）两种切点，可切换。
- 推算「健康体重区间」并提示当前体重与区间的差距。
- 下方色带标尺上以游标标出当前 BMI 所处位置。

## 用法
打开 `index.html`，填写身高体重（或修改标准下拉），结果自动更新。

## 说明
BMI = 体重(kg) ÷ 身高(m)²。BMI 是粗略筛查指标：肌肉量高者可能偏高，老年人或水肿者可能偏低，更准确需结合体脂率、腰围等。

数据不出本机，无需联网。
