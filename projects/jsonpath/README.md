# JSONPath Explorer · JSON 路径查询

在浏览器里查询 JSON 的轻量 JSONPath 工具。输入 JSON 和路径，结果会同时显示匹配值与精确路径，适合检查 API 响应、配置文件和日志样本。

## 支持的语法

- `$`：根值
- `$.users[0].name`：点属性与数组索引
- `$['a.b']` / `$["a.b"]`：包含点号或特殊字符的键
- `$.users[*].name`、`$.*`：对象/数组通配符
- `$..name`、`$..*`：递归下降

实现是无依赖、无 `eval` 的小型解析器；不执行表达式，也不会访问对象继承链。不存在的路径返回空结果。

## 使用

直接打开 `index.html`，粘贴 JSON，填写路径并点击查询。所有数据只留在当前浏览器页面。
