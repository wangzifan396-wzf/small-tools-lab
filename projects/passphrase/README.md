# passphrase · 助记词口令生成

Diceware 风格的助记词口令生成器：从一个 256 词的易读词表中随机抽取若干词拼成口令。相比随机符号串，助记词口令更易记忆；默认 10 个词提供约 80 位估算熵。

## 特性

- **离线零依赖**：纯浏览器运行，词表内置于代码，不上传任何数据。
- **可调**：词数（2–16）、分隔符、首字母大写、末尾追加一位数字。
- **熵估计**：实时显示 `词数 × log₂(256)`（以及可选数字）的熵估值与强度评价。
- **一键复制**：生成的口令可直接复制到剪贴板。

## 用法

打开 `index.html`（双击即可，无需服务器），设置参数后点「生成」。点「再生成一次」可换一组。

## 安全说明

- 默认使用 `crypto.getRandomValues()`；环境不支持安全随机源时会明确报错，不会回退到 `Math.random()`。
- `generate({ rng })` 支持注入返回 `[0, 1)` 的随机函数，主要用于可复现测试；生产环境应保留默认值。
- 词表为通用英文常用词，未做针对性抗猜测优化；请勿用于高价值账户的**唯一**凭据。
