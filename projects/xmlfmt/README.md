# XML 美化 / 压缩

零依赖、纯前端的 XML 排版工具。把压成一行或乱糟糟的 XML 整理成按元素嵌套缩进的可读结构，或压缩成最小体积。

## 功能
- **美化**：以元素为层级逐级缩进（每级 2 空格），自闭合标签（`/>`）不增加缩进。
- **压缩**：去除注释并删除标签之间的空白，缩小体积。
- **安全**：CDATA 块、注释、处理指令（`<? ... ?>`）与属性字符串（`"..."` / `'...'`）内容原样保留，内部 `<` `>` `&` 不会被破坏。

## 用法
打开 `index.html`，粘贴 XML，点「美化」或「压缩」。

## 示例
输入：
```xml
<note><to>A</to><from>B</from></note>
```
美化后：
```xml
<note>
  <to>A</to>
  <from>B</from>
</note>
```

## 实现
`src/xmlfmt.js`，UMD 模块，导出 `beautify` 与 `minify`，无第三方依赖。`node --test` 覆盖嵌套缩进、自闭合标签、属性字符串保护、CDATA 保护与压缩用例。
