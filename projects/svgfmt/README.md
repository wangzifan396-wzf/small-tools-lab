# svgfmt · SVG 压缩 / 美化

SVG 源码的压缩与美化工具。一行去掉注释和冗余空白（便于内联进 HTML/JS），一行排版成缩进清晰的格式（便于阅读与 diff）。

## 特性

- **压缩（minify）**：移除真实 XML 注释并规范标签空白，不改写属性值、CDATA 或文本节点。
- **美化（format）**：按嵌套层级缩进；`text`、`tspan`、`style` 等内容敏感元素保持行内原文。
- **实时统计**：输入 / 输出字节数与节省量一目了然。
- **离线零依赖**：纯浏览器运行，SVG 不会上传到任何服务器。

## 用法

打开 `index.html`，粘贴 SVG 源码，点「压缩」或「美化」。可载入示例快速体验，结果可一键复制。

## 注意

- 格式化器识别引号、CDATA 与文本容器，但不是完整的 SVG/XML 验证器；建议对不可信输入另行做安全校验。
- 不进行语义优化（如合并路径、四舍五入坐标），只做文本层格式化。
