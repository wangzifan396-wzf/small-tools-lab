# CSS 美化 / 压缩

零依赖、纯前端的 CSS 排版工具。把压成一行或乱糟糟的 CSS 整理成带缩进的可读结构，或压缩成最小体积。

## 功能
- **美化**：以 `{` `}` 为层级，规则内部声明逐行缩进（每级 2 空格），选择器与规则之间合理换行。
- **压缩**：去除注释与多余空白，去掉 `}` 前的最后一个分号，缩小体积。
- **安全**：字符串（`"..."` / `'...'`）与注释（`/* */`）内容原样保留，不会被内部空格破坏。

## 用法
打开 `index.html`，粘贴 CSS，点「美化」或「压缩」。

## 示例
输入：
```css
.card{display:flex;gap:8px;padding:16px}
```
美化后：
```css
.card {
  display: flex;
  gap: 8px;
  padding: 16px;
}
```

## 实现
`src/cssfmt.js`，UMD 模块，导出 `beautify` 与 `minify`，无第三方依赖。`node --test` 覆盖缩进、嵌套、字符串 / 注释保护、压缩用例。
