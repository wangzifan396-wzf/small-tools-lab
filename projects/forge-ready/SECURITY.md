# Security policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting for path traversal, report injection, accidental disclosure, or command execution issues. Do not put active credentials or private repository contents in a public issue.

Include the ForgeReady version, operating system, minimal redacted reproduction, and expected behavior. You should receive an acknowledgement within seven days.

## Data handling

ForgeReady operates locally, never executes repository code, and makes no network requests. It writes only the report path explicitly requested by the user.
