# HTML 美化 / 压缩

零依赖、纯前端的 HTML 排版工具。把压成一行或乱糟糟的 HTML 整理成按标签嵌套缩进的可读结构，或压缩成最小体积。

## 功能
- **美化**：以标签为层级逐级缩进（每级 2 空格），`void` 元素（br/img/input 等）不增加缩进，文本节点内联保留。
- **压缩**：去除 HTML 注释并删除标签之间的空白，缩小体积。
- **安全**：`<script>` / `<style>` 块、属性字符串（`"..."` / `'...'`）与注释内容原样保留，不会被内部空格或 `>` 破坏。

## 用法
打开 `index.html`，粘贴 HTML，点「美化」或「压缩」。

## 示例
输入：
```html
<ul><li>a</li><li>b</li></ul>
```
美化后：
```html
<ul>
  <li>a</li>
  <li>b</li>
</ul>
```

## 实现
`src/htmlfmt.js`，UMD 模块，导出 `beautify` 与 `minify`，无第三方依赖。`node --test` 覆盖嵌套缩进、void 元素、属性字符串保护、script 保护与压缩用例。

## 局限
`<pre>` / `<textarea>` 等需保留内部空白的元素会被一并重排；如需保留请分段处理。
