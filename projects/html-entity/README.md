# HTML 实体编解码 (html-entity)

零依赖的 HTML 实体双向转换工具。在浏览器里完成，数据不出本机。

## 功能
- 字符 → 实体：支持「命名实体 / 十进制 / 十六进制」三种输出（命名覆盖最常用的可显示字符，其余非 ASCII 自动用 `&#nnn;`）。
- 实体 → 字符：同时识别 `&amp;` 命名与 `&#123;` / `&#x1F`; 数字实体。
- 一键「互换」输入与结果、「复制结果」。

## 用法
打开 `index.html`，输入内容后点「编码 →」或「← 解码」。

适合转义用户输出、排查 XSS、阅读或生成富文本片段。纯前端、无网络、无依赖。
