# Browser Todo

A tiny local-first task list retained from the original Small Tools Lab. It runs entirely in the browser and stores tasks in `localStorage`.

## Quick start

Open `index.html` directly, or launch it from the [Small Tools Lab catalog](https://wangzifan396-wzf.github.io/small-tools-lab/projects/browser-todo/).

## Usage

Add a task, click its text to toggle completion, and remove completed items when they are no longer useful. No account, server, or network request is required.

## Privacy

Tasks remain in the current browser profile. Clearing site data removes them.
