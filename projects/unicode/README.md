# Unicode 码点查看 (unicode)

零依赖的 Unicode 字符分析工具。在浏览器里逐字符解析，数据不出本机。

## 功能
- 逐字符（按码位，emoji 代理对自动正确拆分）展示：
  - 字符本身
  - 码点 `U+XXXX`
  - UTF-8 字节序列
  - UTF-16 编码（含代理对）
  - 名称 / 类别（ASCII、CJK、假名、韩文、emoji 等）
- 一键复制码点列表。

## 用法
打开 `index.html`，输入任意文本（中英文、emoji、符号均可），点「分析」。

适合调试编码、核对字符身份、理解 UTF-8/UTF-16。纯前端、无网络、无依赖。
