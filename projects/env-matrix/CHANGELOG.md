# Changelog

All notable user-facing changes will be documented here.

## 0.1.0 - 2026-08-03

- Added cross-layer environment-variable discovery for source, examples, CI, containers, deployment manifests, and docs.
- Added required and optional inference with explicit configuration overrides.
- Added 11 coverage, drift, integrity, deployment, and security rules.
- Added deep redaction for sensitive default values.
- Added terminal, JSON, Markdown, and self-contained HTML reports.
- Added severity gates and a reusable GitHub Action.
