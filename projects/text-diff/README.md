# 文本差异

纯前端、零依赖的逐行文本对比工具，基于 LCS（最长公共子序列）算法。

## 功能
- 两段文本（A 原 / B 新）逐行对比。
- 标出：**新增**（+，绿）、**删除**（-，红）、**未变更**（灰，可隐藏）。
- 顶部汇总「+N 新增 / -M 删除 / 未变更 K 行」。
- 一键复制差异文本。

## 用法
打开 `index.html`，在左右两个框粘贴文本，点「对比」。

## 适用场景
- 对比代码、配置、文档的两版改动。
- Code Review 前快速定位差异。
- 检查自己改了哪些行。

数据不出本机，无需联网。超大文本（数千行）对比可能稍慢，属正常。
