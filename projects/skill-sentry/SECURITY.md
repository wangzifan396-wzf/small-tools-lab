# Security

Skill Sentry never executes scanned content, installs dependencies, follows symlinks, or makes network requests. Discovery is bounded by skill, file-count, and file-size limits.

Evidence is capped and recognizable token formats are masked. Reports still contain source paths and code fragments; review them before publishing. Treat scanner findings as review signals, not a guarantee of safety.

Report vulnerabilities privately through [SECURITY.md](../../SECURITY.md).
